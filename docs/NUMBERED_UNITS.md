# Numbered console slots

Each console catalog item supplies slots 01 through stock. Cards, cart entries, booking links, reservations and play sessions retain the slot number. Catalog prices remain shared. Increasing stock exposes the next number; reducing stock is refused while removed numbers have confirmed bookings or active sessions. Numbers identify shop positions within a model, not manufacturer serial numbers.

Confirmation, start, resume and extension recheck the selected slot under the catalog inventory lock. Different slots may run concurrently; the same slot cannot overlap. Older records keep a nullable number instead of guessing which physical console was used. Unassigned active legacy records conservatively hold numbered availability until completed; historical records are retained. Automatic new requests receive a free number on confirmation.

All public pages and the admin panel share the static controller-button background. Auth pages inline the small pattern stylesheet to retain the existing critical CSS loading path.
